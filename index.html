01

Agentic PR Reviewer

AI code review agent for GitHub PRs.

A Next.js app that hands a real GitHub PR diff to an LLM equipped with two tools: post an actionable review comment for ordinary issues, or bypass GitHub entirely and page a human over Slack for critical vulnerabilities (hardcoded secrets, injection, auth bypass, RCE). The frontend streams the agent's reasoning live via a hand-rolled newline-delimited-JSON protocol — an actual line-by-line activity feed, not a fake spinner. Verified against a purpose-built testbed repo with planted SQL-injection, hardcoded-key, and off-by-one bugs, then locked in with an 8-fixture eval harness that still passes 8/8 in dry-run mode. Along the way: root-caused a 403 on posting PR comments to GitHub's PR-comment endpoints actually being Issues-API permissions under the hood, and fixed an ESM/CJS interop break in Octokit by converting to a lazy dynamic import.

  • Next.js
  • Vercel AI SDK
  • Octokit
  • Slack API
  • Eval harness

02

Knowledge App

RAG chat app with citations.

A retrieval-augmented chat app: add sources, ask questions, get answers cited from the exact chunks that were retrieved and reranked — not text the model was merely asked to cite. Per-user data is hard-isolated by namespace across Pinecone and Redis, gated behind GitHub OAuth, rate-limited against abuse, and automatically wiped after 7 days of inactivity via a Vercel Cron job. An automated eval harness scores retrieval hit-rate and LLM-judged answer correctness at 100% (6/6) on the seeded demo set. Shipping it surfaced a real production debugging streak: a Vercel 4.5MB body-limit 413 that crashed the client instead of erroring cleanly, a DOMMatrix is not defined failure traced to a native dependency invisible to Vercel's file tracer, a second near-identical crash in the PDF worker's dynamic import, and a self-caught OAuth regression where re-pasting env vars silently overwrote production GitHub credentials with local-dev ones — caught and fixed in the same session.

  • Next.js
  • Pinecone
  • Upstash Redis
  • Auth.js
  • Vercel Cron

03

Steam Reviews Qualitative Coding Tool

A qualitative coding tool for Steam reviews, with AI-assisted tagging measured against a human coder.

A research tool for qualitative game-studies analysis: ingest Steam reviews, build a codebook, tag text spans by hand, and get AI-suggested codes constrained — via structured outputs with a schema enum — to only the codes that actually exist in the codebook. Nothing is written until a researcher explicitly accepts a suggestion, through the same code path a human tag uses. A reliability dashboard then reports Cohen's kappa between the human and AI coders, validated against a hand-computed textbook example before being trusted. The headline architectural bet: there's no server-side database at all — every visitor runs Postgres-in-WebAssembly (PGlite) locally, persisted to IndexedDB, sidestepping multi-user auth entirely. Hardening included a real race condition (two near-simultaneous "accept suggestion" clicks colliding on a SELECT-then-INSERT), reproduced and fixed with an atomic upsert, plus per-IP rate limiting on the AI routes.

  • Next.js
  • PGlite (Postgres/WASM)
  • OpenAI Structured Outputs
  • Upstash Redis
